HiKey by HumanLink Say hi. Share a key. Stay connected.

Share identity without exposing it.

HiKey is a privacy-first connection handshake for random meetings, events and professional networking. A public key starts the relationship; the receiver alone decides whether any private information becomes visible.

50 fictional demo identities One-way private grants Revocable access GitHub Pages ready
1Share a HiKey

Use a QR, link or memorable code. No phone number is embedded.

2Approve the person

The receiver accepts or declines the connection request.

3Grant selectively

Choose specific private fields, then revoke access whenever required.

Prototype boundary: this single-browser demonstration stores encrypted demo keys locally so both sides can be simulated. A production system needs authenticated APIs, secure device keystores, key recovery, abuse controls and an independent security review.
